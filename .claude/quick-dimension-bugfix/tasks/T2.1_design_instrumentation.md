## Objective
Design the smallest source-level instrumentation that can prove whether each named reference's physical station comes from that exact reference or from an independently derived proxy point.

## Do
1. Identify the minimum logging points inside the main wall-axis flow.
2. Define what must be logged per opening side:
   - label,
   - chosen reference strategy,
   - stable reference string or owner,
   - the point used for projection,
   - the projected station,
   - whether that point is reference-owned or proxy-derived.
3. Keep production behavior unchanged except for added diagnostics.
4. Keep the instrumentation localized to the BUG-11 owner file.

## PASS only if
- the patch plan is minimal,
- it can distinguish reference-owned station from proxy-derived station,
- it does not widen the production scope.

## BLOCKED if
- the existing logging path cannot carry the needed evidence without a broader edit.
