## What to decide

1. **Session shape.** Confirm or refine this starting proposal, and justify any change:

   ```csharp
   public interface ISpreadsheetPdfExporter : IDisposable
   {
       SpreadsheetEngine Engine { get; }
       bool Open(string filePath);
       IReadOnlyList<string> GetSheetNames();
       IReadOnlyList<string> GetNamedRanges(string sheetName);
       bool ExportRegionToPdf(string sheetName, string regionName, string outputPdfPath);
   }
   ```

   Points you must settle explicitly:
   - Does `Open` return `bool` or throw? Today `OpenFile` swallows everything and returns `false`
     (`ExcelInteropService.cs:44-47`), and `ExcelSyncEngine.cs:162` converts that into a thrown
     `InvalidOperationException` with a user-facing message. Preserve the observable outcome.
   - `ExportRegionToPdf` returns the PDF, not the PNG. State who owns the temp PDF lifetime — the
     current code deletes it in `ExportRangeInternal`'s `finally` (line 357), and after the split the
     coordinator owns it. Say so unambiguously.
   - Region resolution order NamedRange → PrintArea → UsedRange stays **inside** the provider, because
     it is COM work. Confirm.
   - Whether `GetSheetNames` / `GetNamedRanges` keep today's swallow-and-return-empty behavior
     (`ExcelInteropService.cs:419-422`, `483-486`). The UI depends on not crashing here.
   - Whether the interface needs a `SpreadsheetEngine Engine { get; }` at all, or whether the
     coordinator alone should carry engine identity for diagnostics. Pick one and justify.

2. **MS Excel COM member inventory.** For each member the MS provider will call, record: the exact
   member, the argument list used today with `file:line`, and a Microsoft Learn citation. Cover at
   minimum: `Application.Visible`, `Application.DisplayAlerts`, `Workbooks.Open`, `Workbook.Close`,
   `Application.Quit`, `Workbook.Worksheets`, `Workbook.Names`, `Name.RefersToRange`,
   `Range.Worksheet`, `Range.Address[false,false]`, `Worksheet.Range[...]`, `Worksheet.UsedRange`,
   `Worksheet.PageSetup` (`PrintArea`, `Zoom`, `FitToPagesWide`, `FitToPagesTall`, the four margins,
   `PaperSize`), and `Worksheet.ExportAsFixedFormat`.

3. **Numeric values of the enums used today**, needed by `T1.2` for the late-bound branch:
   `XlFixedFormatType.xlTypePDF`, `XlFixedFormatQuality.xlQualityStandard`,
   `XlPaperSize.xlPaperEsheet`, `XlPaperSize.xlPaperA3`. Cite a source for each value; do not guess.
   If a value cannot be sourced reliably, mark it `UNSOURCED` and say so — `T1.2` will handle it.

4. **COM release order rules** that must survive: child before parent, no `ReleaseComObject` after
   `Delete`, `Dispose` order workbook → app (`ExcelInteropService.cs:361-378`).
