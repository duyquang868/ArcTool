the only file that defines the `SpreadsheetEngine` enum.

## What to write

One file: `ArcTool.Core/Services/Excel/ISpreadsheetPdfExporter.cs`.

Requirements:

1. Namespace consistent with the folder — check what sibling services in `ArcTool.Core/Services/` use
   before choosing; if `ArcTool.Core.Services` is the convention, use `ArcTool.Core.Services.Excel`.
   State the convention you found in your result file.
2. `public enum SpreadsheetEngine` with the members needed by the locked design (at minimum an
   MS-Excel member and a WPS member). Per contract §8 coding rules, prefix or name enum members so they
   cannot collide with `Autodesk.Revit.DB` types.
3. `public interface ISpreadsheetPdfExporter : IDisposable` with exactly the members locked in `T1.1`.
4. **Engine neutrality is a hard gate (R8/R9).** No signature may mention an Interop type, an `Xl*`
   enum, a WPS ProgID, `Range`, `Worksheet`, `Workbook`, or `object` standing in for a COM object. Only
   `string`, `bool`, `IReadOnlyList<string>`, and the enum are allowed.
5. XML doc comments on the interface and on every member, stating: what the member does, what it
   returns on failure, and who owns the produced file. The temp-PDF ownership rule from `T1.1` must be
   written into the `ExportRegionToPdf` doc comment — that is the single most likely thing a future
   reader gets wrong.
6. Document the region-resolution order (NamedRange → PrintArea → UsedRange) in the doc comment for the
   export member, since it is provider-internal but caller-visible behavior.
7. No implementation, no static helpers, no `#region`, nothing beyond the enum and the interface.
