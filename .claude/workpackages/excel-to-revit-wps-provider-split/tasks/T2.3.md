# T2.3 — Build gate after the engine-neutral files

- depends on: `T2.1`, `T2.2`
- write_scope: result only → `results/T2.3_result.md`
- model: sonnet

## Objective

Prove the two engine-neutral files compile inside the real project before any provider is written. A
failure here is cheap; the same failure discovered in Phase 3 is not.

## Inputs you may read

- `01_SHARED_CONTRACT.md` §7 (the build command)
- `results/T2.1_result.md`, `results/T2.2_result.md`
- The two new files, if you need to diagnose an error:
  `ArcTool.Core/Services/Excel/ISpreadsheetPdfExporter.cs`,
  `ArcTool.Core/Services/Excel/PdfRasterImageService.cs`

Do not read `CLAUDE.md`. Do not run Revit, Excel, WPS, or any MCP tool (R1).

## What to do

1. Run the build:

   ```bash
   "/c/Program Files/Microsoft Visual Studio/18/Community/MSBuild/Current/Bin/MSBuild.exe" ArcTool.Core/ArcTool.Core.csproj -property:Configuration=Debug -property:Platform=x64 -verbosity:minimal -nologo
   ```

2. Record: exit code, every error, every warning. Note that `ExcelInteropService.cs` still exists at
   this point and still compiles — that is expected and correct. Both old and new raster code coexisting
   is intentional at this gate.
3. Compare the warning set against a baseline. If you cannot establish a pre-change baseline, say so and
   attribute warnings conservatively: a warning is "new" only if it names one of the two new files.
4. **You may not fix source files** — you do not own them. If the build fails, diagnose precisely
   (file, line, compiler code, cause) and return `FAIL` with a recommended owner: interface problems go
   back to `T2.1`, raster problems to `T2.2`.

## Verdict rules

- `PASS` — exit code 0, no new errors, no new warnings naming the two new files.
- `PASS_WITH_NOTES` — exit code 0, but a new warning names a new file. Quote it and assess severity.
- `FAIL` — non-zero exit code. Include the diagnosis and the recommended owner.

## Acceptance condition

The result file contains the exact command run, the exit code, the verbatim error/warning lines (or an
explicit statement that there were none), and the verdict on the first line.

## What downstream needs from you

Phase 3 does not start until this is `PASS` or `PASS_WITH_NOTES` with a justification the master accepts.
