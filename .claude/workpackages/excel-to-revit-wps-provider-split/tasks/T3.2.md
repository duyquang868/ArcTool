## What to implement

Full `ISpreadsheetPdfExporter`: engine identity, `Open`, `GetSheetNames`, `GetNamedRanges`,
`ExportRegionToPdf` (including region resolution NamedRange → PrintArea → UsedRange), and `Dispose`.

Behavior targets:

- Region resolution order identical to MS (`ExcelInteropService.cs:512-582`).
- PageSetup normalization identical in intent: print area, `Zoom = false`, fit 1×1, four margins 0, paper
  size with silent fallback. If a member is missing on WPS, follow `T1.2`'s fatal-vs-tolerable ruling for
  that specific member — a missing `PaperSize` is tolerable, a missing `ExportAsFixedFormat` is not.
- `Open` returns `false` on any failure, same as MS, so `ExcelSyncEngine`'s user-facing throw still works.
- `GetSheetNames` / `GetNamedRanges` swallow and return empty, same as MS, so the UI never crashes.
- **After `ExportAsFixedFormat` returns, verify the PDF actually exists on disk** before reporting
  success. WPS may return without throwing and without producing a file; the MS branch never needed this
  check, this branch does.
