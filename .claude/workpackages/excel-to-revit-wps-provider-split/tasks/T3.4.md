## Steps, in this order

1. **Verify the port is complete before deleting anything.** Confirm every live behavior of
   `ExcelInteropService.cs` now exists in a new file, using the old→new mappings in the `T3.1`, `T2.2`,
   and `T3.3` result files. Expected coverage:
   - COM open / enumerate / region-resolve / PageSetup / PDF export → `MsExcelWorkbookPdfExporter.cs`
   - native loaders + render + crop → `PdfRasterImageService.cs`
   - temp-PDF lifetime + PDF→PNG handoff → `SpreadsheetImageExportService.cs`
   - `GetActiveSheetName` and `ExportPrintAreaAsHighResImage` — dead code, intentionally dropped
   If any live behavior is unaccounted for, **stop and return `BLOCKED`**. Do not delete.

2. **Create the backup.** Copy the file verbatim to
   `ArcTool.Core/Services/_backup/ExcelInteropService.cs.bak`, creating the `_backup` folder. Byte-identical
   copy — no edits, no reformatting, no header comment added. The `.bak` extension keeps it out of the SDK
   `.cs` glob, so it cannot compile and cannot cause duplicate-type errors.

3. **Verify the backup.** Compare sizes and line counts, or hash both files. Paste the evidence into your
   result file. A backup you did not verify is not a backup.

4. **Confirm the folder cannot be compiled.** Check that nothing in `ArcTool.Core.csproj` would include
   `_backup/**` (for example a `Compile Include` glob or a `Content` item). If the project would pick it
   up, return `BLOCKED` — you do not own the csproj and nobody in this package does.

5. **Delete the original** `ArcTool.Core/Services/ExcelInteropService.cs`.

6. **Report remaining references.** The three call sites still reference the deleted type at this point —
   that is expected; `T3.5` and `T3.6` fix them next, and the build is knowingly broken between this task
   and `T3.7`. Enumerate them so the master can confirm the rewire tasks cover exactly that set:

   ```bash
   grep -rn "ExcelInteropService" --include=*.cs --include=*.csproj --include=*.xaml . | grep -v "/.claude/worktrees/" | grep -v "/_backup/"
   ```

   Note: stale `.claude/worktrees/agent-*` copies exist and must be excluded — they are not live code.
