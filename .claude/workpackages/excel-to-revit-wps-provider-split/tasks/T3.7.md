## Objective

in the actual source text rather than in someone's assertion.

- The Phase 3 result files

Do not read `CLAUDE.md`. Do not run Revit, Excel, WPS, or any MCP tool (R1).

## Part 1 — Build

```bash
"/c/Program Files/Microsoft Visual Studio/18/Community/MSBuild/Current/Bin/MSBuild.exe" ArcTool.Core/ArcTool.Core.csproj -property:Configuration=Debug -property:Platform=x64 -verbosity:minimal -nologo
```

Record exit code, every error, every warning. Attribute each warning to a file. A warning is "new" only if

You may **not** fix source files — you own none. On failure, diagnose (file, line, compiler code, cause)
and name the owning task: interface → `T2.1`, raster → `T2.2`, MS provider → `T3.1`, WPS provider →
`T3.2`, coordinator → `T3.3`, engine rewire → `T3.5`, window rewire → `T3.6`.

## Part 2 — Static isolation audit

Run each command and paste the command plus its verbatim output. Exclude stale worktree copies with
`| grep -v "/.claude/worktrees/"` and exclude `/_backup/` where noted.

1. **No Interop or `Xl*` enum in the WPS file (R9)** — expect no output:
   ```bash
   grep -nE "Microsoft\.Office\.Interop|XlFixedFormat|XlPaperSize|Xl[A-Z][A-Za-z]*\.|Excel\.Application" ArcTool.Core/Services/Excel/WpsWorkbookPdfExporter.cs
   ```
2. **No WPS or late binding in the MS file (R8)** — expect no output:
   ```bash
   grep -nE "GetTypeFromProgID|InvokeMember|KET\.|ET\.Application|Kingsoft|KWPS|WPS\.Application" ArcTool.Core/Services/Excel/MsExcelWorkbookPdfExporter.cs
   ```
3. **No file except the coordinator names both branches (R8).** For each of the five new files, check
   whether it mentions both an MS-Excel marker and a WPS marker. Only
   `SpreadsheetImageExportService.cs` may. Report the per-file result as a table.
4. **Zero live references to the deleted type** — expect only the `_backup` hit:
   ```bash
   grep -rn "ExcelInteropService" --include=*.cs --include=*.csproj --include=*.xaml . | grep -v "/.claude/worktrees/"
   ```
5. **No COM in the raster service** — expect no output:
   ```bash
   grep -nE "Microsoft\.Office\.Interop|GetTypeFromProgID|InvokeMember|Worksheet|Workbook" ArcTool.Core/Services/Excel/PdfRasterImageService.cs
   ```
6. **The `COMReference` survived** — expect a hit:
   ```bash
   grep -n "Microsoft.Office.Interop.Excel" ArcTool.Core/ArcTool.Core.csproj
   ```
7. **The csproj was not modified by this package**:
   ```bash
   git diff --stat -- ArcTool.Core/ArcTool.Core.csproj
   ```
   Expect no output. Any diff is a contract violation — report it as a finding.
8. **Backup exists** (contract R12):
   ```bash
   ls -la ArcTool.Core/Services/_backup/
   ```
9. **Parity constants intact** — confirm `240` and `300` survive in the raster service, and that the
   `ExportAsFixedFormat` argument list in the MS provider still reads
   `xlTypePDF, path, xlQualityStandard, false, false, 1, 1, false`. Quote both.

## Verdict rules

- `PASS` — build exit code 0 with no new errors or warnings, and all nine audit checks match expectations.
- `PASS_WITH_NOTES` — build clean, audits pass, but a cosmetic finding exists. Quote it.
- `FAIL` — build failure, or any audit check violated. Name the violated invariant (`R8`, `R9`, `R12`, …)
  and the owning task.

## Acceptance condition

Verdict on the first line. Then the build section, then all nine audit checks with verbatim output. No
check may be reported as "passed" without its command output shown.

## What downstream needs from you

Phase 4 starts only on `PASS`. `T4.1` builds on your parity-constant quotes; `T5.3` cites your verdict.
