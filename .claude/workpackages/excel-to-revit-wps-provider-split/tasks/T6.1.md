## Locked decisions to record

Phrase each as an invariant a future session must not silently reverse:

1. Spreadsheet automation is provider-split. WPS COM and MS Excel COM never share a file. Only
   `SpreadsheetImageExportService` knows both exist.
2. The WPS provider is late-bound only: no Interop reference, no `Xl*` enum, numeric constants with recorded
   provenance. Converting it to early binding would break WPS-only machines.
3. Engine precedence is MS Excel first, WPS as fallback, auto-detected, with no UI picker and no settings
   override.
4. The PDF file on disk is the convergence point. Everything after it — 300 DPI render, threshold-240 crop,
   Revit `ImageType`/`ImageInstance` — is engine-agnostic and shared.
5. Temp-PDF lifetime belongs to the coordinator, not the provider. State where the old `finally` lived so a
   future reader does not "restore" it.
6. `ExcelInteropService.cs` is retired; the verbatim original is at
   `ArcTool.Core/Services/_backup/ExcelInteropService.cs.bak`.
7. `GetActiveSheetName` and `ExportPrintAreaAsHighResImage` were dead code and were intentionally dropped.
8. `ClosedXML` / OpenXML SDK / NPOI cannot substitute for either engine — the feature renders, it does not
   parse. Record this so the question is not reopened.
