## 4. Constraints to prevent false pass

A fixture run is **invalid** if any of these conditions hold:

1. Wall axis length is not 8000 mm ± 1 mm (tolerance for manual placement)
2. Any opening width differs from spec by more than 5 mm
3. Any opening left-jamb station differs from spec by more than 10 mm
4. Wall has joins at either end (introduces mid-run joint candidates not in the oracle)
5. Wall intersects another wall mid-span (introduces mid-run joint candidates)
6. Openings are not hosted in the specified wall
7. Any opening is mirrored/flipped after placement (Session 4.2 tests that; keep Session 4.1 clean)
8. Grids are visible in the view (disabled in wall-axis flow, but their presence signals operator misunderstanding)
9. The combined XML file contains candidates from sources other than wall anchors and the three specified openings

If any invalid condition is detected in evidence review, the run must be repeated with a corrected fixture before any oracle comparison.
