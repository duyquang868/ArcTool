Neutrality argument per edit:

### 2. `ArcTool.Core/Models/QuickDimensionContract.cs`
Touched types / edits:
- added `QuickDimensionCollectionTimingTrace` as a small managed payload type holding five timing values;
- extended `QuickDimensionReadOnlyResult` with:
  - an optional constructor parameter `QuickDimensionCollectionTimingTrace? timingTrace = null`;
  - a read-only `TimingTrace` property.

Why this extra file was required:
- the engine and XML log service need a stable handoff surface for timing data;
- without extending the shared read-only result model, the timing payload could not reach XML serialization without hidden global state or an unauthorized side-channel;
- this is a narrow contract extension only, with no change to existing candidate/audit semantics.

Neutrality argument:
- the new type carries only scalar timing values;
- the existing `QuickDimensionReadOnlyResult` data shape remains backward-compatible because the new constructor parameter is optional;
- existing collector callers still compile without behavior change;
- no existing result property meaning changed.

- added `BuildPerformanceTimingsElement(...)`
  - emits a `<PerformanceTimings ... />` child block under `ReadOnlyResult`;

Neutrality argument:

- no command control flow or audit logic changed;
- the new XML block only exposes timing metadata already captured in memory.
