## Objective
Author the exact clean fixture the operator must build for Session 4.1 so the feature can be judged against a pre-written analytic oracle rather than ad hoc expectations.

## Do
1. Specify one minimal but non-trivial clean fixture using only supported scope:
   - one straight non-curtain host wall,
   - plan view only,
   - explicit wall length,
   - explicit opening count, type mix, widths, and target stations,
   - no joins, no grids, no arc walls, no linked content.
2. State the exact shell(s) to run and why.
3. Choose values that make manual verification obvious in millimetres and avoid tolerance ambiguity.
4. State what the operator must photograph or annotate in the screenshot.
5. State any fixture constraint that prevents a false pass.

## PASS only if
- The fixture is fully within MVP scope.
- Every geometric input needed for an oracle is explicit.
- The result is concise enough for the operator to build without inference.

## NO_GO if
- A trustworthy clean fixture cannot be specified without reopening unsupported scope.
