## Objective
Write the pre-runtime predictions for every Session 4.2 case so the package can test whether the implementation behaves as expected rather than rationalizing after the fact.

## Do
1. For each case from `T3.1`, predict one of:
   - Supported,
   - Unsupported-by-design,
   - Defect risk worth watching.
2. For supported cases, predict the expected visible and audit outcome.
3. For unsupported cases, predict the honest failure mode or reduced behavior that would still count as acceptable.
4. Name the key signal that would falsify each prediction.

## PASS only if
- Every case has a prediction before EV-2 is requested.
- Predictions are specific enough for later evidence tasks to confirm or reject.
- Mirror/flip remains an explicit unresolved probe, not hand-waved.

## BLOCKED if
