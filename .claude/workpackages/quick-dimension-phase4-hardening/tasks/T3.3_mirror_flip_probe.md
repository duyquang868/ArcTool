## Objective
Design the explicit observation probe that settles whether mirrored/flipped openings have any residual effect now that named references own their stations.

## Do
1. State the hypothesis under test in one sentence.
2. Define the minimum mirrored/flipped case pair(s) needed to settle it.
3. Specify exactly what the operator must capture for those cases:
   - family orientation / flip state observation,
   - created/no-created outcome,
   - audit order and segment values,
   - any visible inversion or lack of inversion.
4. State what evidence would confirm the hypothesis and what would falsify it.

## PASS only if
- The probe isolates mirror/flip from unrelated geometry differences.
- Later EV-2 judges can answer the question from the requested evidence alone.

## BLOCKED if
- The predictions do not narrow the hypothesis enough to design a discriminating probe.
