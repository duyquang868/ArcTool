## Objective
Judge the EV-2 evidence for the cases expected to be straightforwardly supported: empty/single/simple multi-opening and dense but still valid supported layouts.

## Do
1. Compare each supplied case to its prediction.
2. Verify visible segment values and any available audit gates.
3. State whether each case is Supported or Defect.
4. Isolate any defect symptom by case id and observable evidence.

## PASS only if
- Every reviewed case gets its own verdict.
- The result distinguishes "supported but slower/noisier" from true correctness defects.
- It does not comment on cases outside its assigned subset.

## BLOCKED if
- The EV-2 excerpt for the assigned cases is incomplete.

## Downstream needs
- `T3.8` needs per-case verdicts and any defect escalations.
