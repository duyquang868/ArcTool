## Objective
Predict the acceptable safe-failure outcome for each Grid variant before EV-3 is requested.

## Do
1. For each Grid variant, predict the honest acceptable behavior:
   - no dimension,
   - explicit cancel,
   - honest diagnostic,
   - or another non-crashing reduced outcome.
2. State what would count as a defect:
   - silent wrong dimension,
   - crash,
   - misleading success,
   - accidental support widening.
3. State whether any XML is expected and how its presence or absence should be interpreted.
4. Keep the predictions specific enough for `T4.4` to confirm or reject.

## PASS only if
- Every variant has one clear acceptable safe-failure prediction.
- The result explicitly forbids treating accidental created dimensions as success.

## BLOCKED if
- The matrix cases are too vague to predict behavior concretely.

## Downstream needs
- `T4.3` needs exact expected outcomes and evidence requests.
