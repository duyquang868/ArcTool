## Do
1. Turn the Grid variant matrix into a concrete run order.
2. For each variant, specify:
   - setup prerequisite,
   - command flow to attempt,
   - what visible outcome to capture,
   - whether XML is expected or optional.
3. Request only the evidence needed for `T4.4`:
   - no-dimension / cancel / dialog outcome,
   - any XML path,
   - screenshot,
   - optional journal excerpt.
4. Update `04_EVIDENCE_QUEUE.md` only if needed to align EV-3 wording.

## PASS only if
- A human can run EV-3 without assuming Grid is supported.

- The runbook does not ask the operator to modify code or enable hidden modes.
