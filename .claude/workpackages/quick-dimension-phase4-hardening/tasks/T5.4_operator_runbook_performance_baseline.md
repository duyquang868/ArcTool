## Objective
Write the operator runbook for collecting the first real Quick Dimension performance baseline.

## Do
1. Specify the model-scale requirement for a meaningful baseline and how the operator reports scale:
   - wall count,
   - door + window count,
   - view element count.
2. Specify the run plan:
   - which walls / shells to run,
   - how many repetitions,
   - whether a warm-up run is required and why.
3. Specify what timing evidence to return and where it appears.
4. Update `04_EVIDENCE_QUEUE.md` only if needed to align EV-4 wording.
5. Keep the request small enough to be practical on one operator session.

## PASS only if
- The runbook yields comparable numbers, not a single unreproducible sample.
- The scale descriptors are explicit.
- The evidence request matches what `T5.5` needs to localize a hotspot.

## BLOCKED if
- No instrumented build is available.
