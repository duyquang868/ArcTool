## Objective
If optimization is authorized, design exactly one safe single-file patch. If it is rejected, record the rejection durably.

## Do

### If `T5.6` = GO
1. Design one minimal change to the named collector file.
2. State the invariants the patch must not disturb:
   - station values,
   - reference identity and ownership,
   - candidate ordering,
   - diagnostics,
   - BUG-10 and BUG-11 fix shapes.
3. State how the change will be verified statically before build.
4. Keep the patch small enough to review in one pass.

### If `T5.6` = NO_GO
1. Record why optimization was rejected, with the measured numbers.
2. State the condition under which a future session should revisit it.

## PASS only if
- The result contains either one concrete patch design or one clear rejection record.
- A GO design cannot plausibly change candidate output.
- No second file is introduced.
