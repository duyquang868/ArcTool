## Objective
Write the EV-6 operator runbook for the minimum ArcTool regression set that must be rechecked before durable closure.

## Do
1. Turn the `T6.1` surface list into exact operator steps.
2. Require the operator to report the build provenance they loaded:
   - baseline-only final build, or
   - optimized final build.
3. Require evidence for each declared regression surface:
   - command launches,
   - candidate/log path still works where expected,
   - created dimension output stayed correct where runtime execution is part of the surface,
   - no new crash or cancellation behavior appeared.
4. Update EV-6 in `04_EVIDENCE_QUEUE.md` with the exact evidence request.
5. Keep the runbook short enough for one operator session.

## PASS only if
- EV-6 asks for exactly the evidence needed to judge regression.
- The runbook matches the actual changed-file blast radius.
- `04_EVIDENCE_QUEUE.md` is the only evidence file touched.

## BLOCKED if
- `T6.1` did not name a concrete runtime surface.
