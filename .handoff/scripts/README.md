# Retained session scripts

Permanently retained helper scripts generated for ArcTool sessions.

Rules:
- Nothing here is deleted. Scripts are durable, reusable assets.
- A script that legitimately belongs next to the subsystem it serves (for example
  `.codebase-memory/run-cbm.cmd`) may live outside this folder, but must still be listed in
  `../SCRIPT_USAGE_LOG.md` with its real repository path.
- Read `../SCRIPT_USAGE_LOG.md` before writing a new helper so an existing script is reused first.
