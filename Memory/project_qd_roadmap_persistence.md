Quick Dimension roadmap for ArcTool should not be pasted in full into `CLAUDE.md`; keep the detailed multi-phase/session/section roadmap in a dedicated roadmap or dossier file and keep `CLAUDE.md` limited to a short pointer plus current status.

**Why:** The user is concerned that a long roadmap would pollute the root operating document and require noisy updates after every phase/session.

**How to apply:** For future QD sessions, load the dedicated roadmap/dossier first, update only its progress/status, and update `CLAUDE.md` only when high-level scope/status changes matter for future implementation context.
